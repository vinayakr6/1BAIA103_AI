Informed Search & Greedy Best-First Search

Learn how heuristic information guides a search toward a goal. Build intuition for h(n), OPEN/CLOSED lists and Greedy Best-First Search by running a working interactive search experiment.

Beginner30–35 minInformed SearchHeuristicsGreedy Best-First

Learning Objectives

  • Explain informed (heuristic) search.
  • Define a heuristic function h(n).
  • Understand why problem-specific knowledge can reduce unnecessary exploration.
  • Explain Greedy Best-First Search.
  • Trace OPEN and CLOSED lists.
  • Understand why greedy search is not generally optimal.

1. Theory: Informed Search

Informed search uses additional information about the problem to guide exploration. The key idea is a heuristic function h(n), which estimates the cost of the cheapest path from node n to a goal state. For route finding, straight-line distance is a common example of a heuristic. fileciteturn12file1

Heuristic h(n)

An estimate of the remaining cost from a node to a goal.

OPEN

Nodes generated but not yet expanded.

CLOSED

Nodes that have already been expanded.

Why use a heuristic? It can focus the search on promising states instead of exploring the search space without guidance. fileciteturn12file3

2. Pure Heuristic Search

The supplied VTU material describes pure heuristic search as expanding nodes according to their heuristic value. At each step, the node with the lowest h(n) is selected. Child nodes are evaluated and placed into OPEN according to their heuristic value. fileciteturn12file0turn12file3

3. Greedy Best-First Search

Greedy Best-First Search selects the node that appears best at the moment according to h(n). It is commonly implemented with a priority queue, giving priority to nodes with the lowest heuristic value. The supplied VTU material emphasizes that it can find a goal quickly by focusing on promising paths, but it is not an optimal algorithm. fileciteturn12file17turn12file18

Basic Procedure

  1. Insert the start node in OPEN.
  2. Select the OPEN node with the lowest h(n).
  3. Move it to CLOSED.
  4. Generate successors.
  5. Add appropriate successors to OPEN.
  6. Repeat until the goal is reached or OPEN is empty.

Why “Greedy”?

It chooses what looks best right now. It does not include the path cost already spent in its selection rule.

Selection: lowest h(n).

Greedy Best-First can behave poorly in some cases, can get stuck in loops without suitable repeated-state handling, and is not guaranteed to return the least-cost solution. fileciteturn12file19

Predict

Before clicking Run Search, identify which node will be selected after S is expanded. Choose the node with the smaller h(n).

Explain

After the run, explain why the algorithm selected that node even if another route might eventually be cheaper.

Change the heuristic

Select Misleading heuristic and run again. Compare the expansion order.

Key question

Does the heuristic value tell us the exact cost already spent? No. Greedy search uses h(n), not g(n).

9. Reflection & Viva Questions

  1. What is informed search?
  2. Define heuristic function h(n).
  3. Why can a heuristic reduce unnecessary exploration?
  4. Explain OPEN and CLOSED.
  5. Describe the steps of Greedy Best-First Search.
  6. Why is Greedy Best-First called greedy?
  7. Why is Greedy Best-First Search not optimal?
  8. Differentiate UCS, Greedy Best-First and A* using g(n), h(n) and f(n).
Lab conclusion: Informed search adds guidance to the search process. Greedy Best-First Search chooses the currently most promising node using h(n), which can make search faster but does not guarantee a least-cost solution.
