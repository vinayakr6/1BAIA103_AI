A* Search

Combine the cost already spent with a heuristic estimate of the remaining cost. Explore how A* uses f(n)=g(n)+h(n) to guide search and why admissible heuristics are important for cost-optimality.

1. Theory: A* Evaluation Function

The supplied Norvig reference defines A* as a best-first search using f(n)=g(n)+h(n), where g(n) is the path cost from the initial state to n and h(n) estimates the cost of the shortest path from n to a goal. Thus f(n) estimates the cost of the best solution that continues through n. fileciteturn13file0

g(n)

Actual cost accumulated from the start to node n.

h(n)

Estimated cost from n to a goal.

f(n)

Total evaluation: g(n)+h(n).

Core rule: A* expands the frontier node with the lowest f(n).

2. Admissible & Consistent Heuristics

An admissible heuristic never overestimates the true cost to reach a goal; it is therefore optimistic. The supplied reference states that A* is complete and that cost-optimality depends on properties of the heuristic. fileciteturn13file0turn13file1

A heuristic is consistent if for every node n and successor n′, h(n) ≤ c(n,a,n′)+h(n′). The reference notes that every consistent heuristic is admissible, and with a consistent heuristic A* is cost-optimal. fileciteturn13file1

PropertyMeaningWhy it matters
AdmissibleNever overestimates remaining goal cost.Supports cost-optimal A* under the stated conditions.
ConsistentSatisfies the triangle-inequality-style condition.Ensures nondecreasing f along paths and supports graph-search optimality.

5. Manual Calculation

At A

If g(A)=1 and h(A)=6:

f(A)=1+6=7

At B

If g(B)=4 and h(B)=3:

f(B)=4+3=7

At G

For a goal, h(G)=0:

f(G)=g(G)

A* does not simply chase the smallest h(n). It balances what has already been paid, g(n), with the estimated remaining cost, h(n).

6. Observe Search Contours

The supplied reference describes A* search as expanding nodes in increasing f-cost. With a good heuristic, the resulting contours become more focused toward a goal than uniform-cost search contours. fileciteturn13file2

UCS

Uses g(n), so its expansion pattern is based on accumulated cost from the start.

A*

Uses g(n)+h(n), allowing domain knowledge to focus search toward promising goal-directed regions.
