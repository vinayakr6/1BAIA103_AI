  1. Performance measure: how success is evaluated.
  2. Percept sequence: information received so far.
  3. Prior knowledge: what the agent already knows about its environment.

Important: Rational does not mean “always successful.” A rational agent selects the action expected to maximize performance based on what it has perceived, knows and can do.

Sensors include eyes, ears, nose, skin and other sensory organs. Effectors include hands, legs and mouth. fileciteturn10file14

Robotic Agent

Sensors can include cameras and infrared range finders; effectors include motors and actuators. fileciteturn10file14

Software Agent

Uses software inputs and produces programmed digital actions, such as writing files, sending information or displaying output. fileciteturn10file16

Five Agent Types

1. Simple Reflex

Chooses an action based on the current percept. It works best when the relevant state is observable.

2. Model-Based Reflex

Maintains an internal state to represent aspects of the world that are not directly observable. fileciteturn10file18

3. Goal-Based

Chooses actions with a goal or desired future state in mind.

4. Utility-Based

Uses a utility measure to compare desirable outcomes and select among alternatives.

5. Learning Agent

Improves its behaviour using experience. The supplied course material identifies learning element, critic, performance element and problem generator as its four components.

4. Nature of Task Environments

Environment properties influence the design of a suitable agent. The supplied material covers the following dimensions. fileciteturn10file17 fileciteturn10file8

Fully / Partially Observable

Fully observable: sensors provide the complete relevant state. Partially observable: information is incomplete or noisy.

Single / Multiple Agents

Single: one agent. Multiple: more than one agent; interactions can be competitive or cooperative.

Deterministic / Non-deterministic

Deterministic: next state is determined by current state and actions. Non-deterministic: outcomes have uncertainty.

Episodic / Sequential

Episodic: each episode is independent. Sequential: current actions can affect future decisions.

Static / Dynamic

Static: environment does not change while the agent deliberates. Dynamic: it can change while the agent is deciding. Semi-dynamic is an intermediate case.

Discrete / Continuous

Discrete: distinct states, percepts or actions. Continuous: values such as time, location or speed can vary continuously.

Known / Unknown

Known: outcomes or outcome probabilities for actions are given. Unknown: the agent may need to learn how the environment works.

Accessible / Inaccessible

Accessible: complete and accurate environment information is available through sensing. Inaccessible: complete information cannot be obtained.
