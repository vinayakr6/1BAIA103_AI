Search, BFS, DFS & Uniform Cost Search

Explore how an AI system searches a state space to find a path to a goal. Compare Breadth-First Search, Depth-First Search and Uniform Cost Search through a working graph simulator.

1. Theory: Problem-Solving Agent

A problem-solving agent decides what to do by formulating a goal, formulating a problem and searching for a sequence of actions that reaches a goal state. The search process can be viewed as exploring a state space.

Initial State

The state from which the search begins.

Actions

Possible operations available from a state.

Transition Model

Describes the state resulting from applying an action.

Goal Test

Checks whether a state satisfies the desired goal.

Path Cost

Numerical cost associated with a path from the initial state.

Solution

A sequence of actions that reaches a goal state.

Search problem: Find a sequence of actions that transforms the initial state into a state that passes the goal test.

2. Uninformed Search

Uninformed, or blind, search does not use additional problem-specific information about how close a state is to the goal. It uses the information supplied by the problem formulation, such as the initial state, actions, transition model and goal test.

MethodMain ideaTypical data structureImportant property
BFSExpand the shallowest unexpanded node first.FIFO queueComplete; optimal when every step has the same cost.
DFSExpand the deepest unexpanded node first.LIFO stackCan use little memory, but may go deep down an unproductive branch.
UCSExpand the node with the lowest path cost g(n).Priority queueComplete and optimal when step costs are positive.
Key distinction: BFS is driven by depth, DFS by depth-first exploration order, while UCS is driven by accumulated path cost.

3. BFS, DFS and UCS at a Glance

Breadth-First Search

Explores level by level. It is useful when shallow solutions are expected and step costs are equal.

Idea: oldest frontier node first.

Depth-First Search

Follows one branch as deeply as possible before backtracking.

Idea: newest frontier node first.

Uniform Cost Search

Always chooses the frontier path with the smallest accumulated cost.

Idea: lowest g(n) first.

5. Observe the Difference

QuestionWhat to observe
Which method reaches a shallow goal first?BFS prioritizes shallow depth.
Which method may follow a deep branch before exploring alternatives?DFS.
Which method notices that A→B→E→G is cheaper than A→C→D→G?UCS, because it compares accumulated path costs.
Why can BFS return a more expensive path?With unequal edge costs, BFS minimizes number of edges rather than total cost.
Important: “Shortest” can mean fewest steps or lowest total cost. BFS and UCS answer different questions when edge costs differ.

6. Manual Trace Challenge

Before running the simulator, predict the first few nodes expanded when searching from A to G.

BFS

Think level by level. The frontier behaves like a queue.

Prediction: A → B, C → ...

DFS

Think deepest first. The exact order depends on the successor ordering.

Prediction: A → one child → deeper child → ...

UCS

Track g(n), the total cost from A to each frontier node.

Prediction: A → B(cost 1) → E(cost 2) → ...

Question

Which algorithm is most appropriate when path costs matter and can differ?

Answer: UCS, assuming its conditions are satisfied.
