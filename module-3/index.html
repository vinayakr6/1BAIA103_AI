How to Use the Module

  1. Read the theory and instructions.
  2. Generate the random dataset.
  3. Run the model.
  4. Change one setting and compare.
  5. Complete the quiz and reflection.
  6. Mark the lab complete.
Dataset rule: Model simulators use random datasets capped at 10 rows and 2–5 columns, with at least one feature and one label where a labelled model requires them.
