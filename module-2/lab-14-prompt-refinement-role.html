How to use this lab: Start with the weak prompt, run it, then click Improve. Add a role, audience, context and output requirements. Compare the before and after versions.

Theory

Prompt engineering is iterative. The supplied material explicitly recommends testing different prompts, rephrasing a prompt and adding context when the result is not satisfactory. Role prompting can be used as a practical refinement strategy by specifying an appropriate perspective or expertise for the task.
