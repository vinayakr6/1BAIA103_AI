How to use this lab: Fill each field and click Build Prompt. Read the assembled prompt, copy it, then change one field at a time and observe how the instruction changes.

Theory

The Instructions Prompt Technique gives the model explicit directions about what it should do. Clear instructions can specify the task, relevant context, restrictions, audience, tone and desired response format.
